## 📝 5. App Review Information (iOS)

```
APP PURPOSE
Mestio helps residents of housing estates and cooperatives report and track
maintenance issues (plumbing, electrical, elevator problems), and helps
property managers and technicians assign, resolve, and communicate about
those reports in one shared app.

HOW TO ACCESS THE APP
This app supports guest access, but a one-time registration step is required
before reaching the main app (this app is community/estate-based — every
account must belong to a "housing estate", identified by an invitation code).

On the Welcome screen, tap "Continue as guest". You will land on a short
registration form: enter any name and phone number, then enter the invitation
code TEST-1234-ABCD when prompted. This code joins a demo estate as a
resident immediately (no approval wait) and unlocks the main app.

The "Log in to existing account" button on the Welcome screen is only
intended for returning users who previously upgraded a guest account via the
in-app profile flow. It is NOT required to review this app. Please use
"Continue as guest" + the invitation code above to proceed.

CORE USER FLOW (SUGGESTED REVIEW PATH)
1. Launch the app → Welcome screen appears.
2. Tap "Continue as guest".
3. Fill in name + phone, enter invitation code TEST-1234-ABCD, submit.
4. On the home screen, tap the "+" button to create a maintenance report
   (title, category, description, optional photo).
5. Open the report from the list to see its status stepper and add a comment.
6. Open the Profile tab to see account info, data export, and Delete Account.

EXTERNAL SERVICES
- Supabase — authentication (anonymous + optional email upgrade), database,
  storage, realtime. https://supabase.com
- Firebase — push notifications (Cloud Messaging), crash reporting (Crashlytics).

REGIONAL AVAILABILITY
The app functions consistently across all regions and languages where it is
distributed. There are no regional differences in features or content.

REGULATED INDUSTRY
Not applicable. This app does not operate in a regulated industry.

aivolux@gmail.com
```
