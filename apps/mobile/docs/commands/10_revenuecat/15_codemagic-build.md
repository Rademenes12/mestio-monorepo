# Intro

Twoim zadaniem jako agenta AI jest poprowadzić mnie przez wypchnięcie zmian i uruchomienie builda w Codemagic.

CEL: Zmiany z RevenueCat są wypchnięte do repo, a Codemagic uruchamia nowy build Android + iOS.

# Task

1. Poproś mnie, żebym zrobił `git push`. Najprościej: VS Code → Source Control → Sync Changes.

2. Poproś mnie, żebym wszedł do Codemagic, otworzył aplikację i przed startem builda upewnił się, że zaznaczone są **Android** i **iOS** a następnie kliknął **Start new build**.

3. Poproś mnie, żebym po uruchomieniu builda napisał `next`.

## FINISH

Nie przechodź dalej dopóki nie napiszę `next`.
Gdy napiszę `next`, przejdź do `docs/commands/10_revenuecat/16_app-store-submit-products.md`.
