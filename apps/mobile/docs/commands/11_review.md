# Etap `11_review`

## Stan workflow

Gdy zaczynasz ten etap, przeczytaj `STATE.md` i zaktualizuj go tak, aby wskazywał:
- `Aktualny etap`: `review`
- status etapu `review`: `🟡 in-progress`

Aplikacja ma już zaimplementowane główne funkcje MVP i jest opublikowana na sklepy Google Play i App Store.

Pozostało jeszcze dodać proszenie o ocenę w odpowiednich momentach. W tym etapie wdrożymy in-app review.

Będziesz zaraz przechodził przez kolejne kroki po kolei.

# Kroki tego etapu

1. `01_review-app-store-id.md` - Pobierzemy App Store ID.
2. `02_review-positive-actions.md` - Wybierzemy pozytywne akcje.
3. `03_review-implement.md` - Podepniemy gotowy mechanizm in-app review.
4. `04_review-debug-mode.md` - Sprawdzimy tryb debug.
5. `05_review-test.md` - Opiszemy testowanie review.
6. `06_review-finish.md` - Zamkniemy etap review.

# Start

Wykonaj polecenie z pliku `docs/commands/11_review/01_review-app-store-id.md`.

Nie przechodź sam do kolejnych kroków bez mojego polecenia.
