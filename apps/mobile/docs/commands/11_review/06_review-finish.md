# Intro

Twoim zadaniem jako agenta AI jest zakończyć etap in-app review.

CEL: Wiem, że review flow jest gotowy i mogę przejść do kolejnego etapu pracy nad aplikacją.

# Task

1. Podsumuj krótko, że etap in-app review jest zakończony:
   - numeryczne Apple ID jest w kodzie jako app-specific stała
   - positive actions są wybrane i podpięte
   - debug alert działa w debug mode
   - prawdziwy `requestReview()` działa tylko poza debug mode
   - UI używa `ReviewPresenter`, a nie bezpośrednio `InAppReview.instance`
   - Profil ma akcje `Rate this app` / `Oceń aplikację` i `Send feedback` / `Wyślij opinię`

2. Powiedz mi, że etap `review` jest zamknięty.

3. Zaktualizuj `STATE.md`: ustaw etap `review` jako `✅ done`, ustaw `Ostatni zakończony etap` na `review`, ustaw `Aktualny etap` na `finalize` i upewnij się, że etap `finalize` ma status `⬜ not-started`.

4. Powiedz mi, że następnym etapem jest `12_finalize.md`.

5. Zasugeruj otwarcie nowej rozmowy/sesji i wklejenie:
   `Wykonaj: docs/commands/12_finalize.md`

6. Jeśli chcę kontynuować w tej samej rozmowie, powiedz że mogę napisać `next`.

## FINISH

Powiedz, że review jest gotowe i mogę przejść do etapu `finalize`, kiedy będę gotowy.
