# Intro

Twoim zadaniem jako agenta AI jest zrealizowanie poniższych poleceń.

CEL: Utworzenie nowego git repository

# Task

1. Upewnij się, że jesteś w folderze z projektem Flutter.
2. Wykonaj `git init`
3. `git add .`
4. `git commit -m "Initial commit"`
5. Wykonaj `flutter --version` i sprawdź, czy w systemie jest zainstalowany Flutter w wersji co najmniej `3.41.4`.
- Jeżeli Flutter nie jest zainstalowany albo wersja jest starsza niż `3.41.4`, nie przechodź dalej, dopóki nie wykonam `flutter upgrade` i nie potwierdzę, że mam już odpowiednią wersję.
- Jeżeli mam problem, podaj mi dokładne instrukcje co mam wpisać i gdzie, zakładając, że jestem osobą nietechniczną.
6. Wykonaj `flutter pub get`

Jeżeli nie masz uprawnień, poproś mnie, abym zrobił to sam dając mi dokładne instrukcje co mam wpisać i gdzie. Zakładaj, że jestem osobą nietechniczną.
