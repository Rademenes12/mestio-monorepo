# Intro

Twoim zadaniem jako agenta AI jest zakończyć kursowy workflow projektu.

CEL: Repozytorium nie zawiera już dokumentowego mechanizmu prowadzenia przez etapy kursu i jest gotowe do dalszej, samodzielnej rozbudowy aplikacji.

# Task

1. Przed usunięciem `STATE.md` zaktualizuj go tak, aby etap `finalize` miał status `✅ done`, `Ostatni zakończony etap` był ustawiony na `finalize`, a `Aktualny etap` pozostał `finalize`. Jeśli platform sync jest możliwy, zsynchronizuj `stage: "finalize"`, `status: "done"` zgodnie z instrukcją w `STATE.md`.

2. Usuń sekcję `# Course Workflow` z `AGENTS.md` i `CLAUDE.md`. Nie zmieniaj pozostałej treści tych plików.

3. Usuń rootowy plik `STATE.md`.

4. Usuń katalog `docs/commands/` razem z całą zawartością.

5. Zrób commit z wiadomością `chore: final cleanup`.

6. Pogratuluj mi krótkim, lekkim wierszykiem domknięcia całego flow tworzenia aplikacji. Na końcu użyj dokładnie `🎉🎉🎉`.

## FINISH

Powiedz, że od teraz droga wolna, mogę rozbudowywać aplikację według własnych zasad i warto często wydawać aktualizacje. Życz mi powodzenia.
