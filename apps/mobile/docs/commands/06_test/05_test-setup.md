# ZADANIE: 05_test_setup

## CEL
Przygotowanie środowiska do testów integracyjnych.

## KROKI DO WYKONANIA:
1. Sprawdź czy nie ma niezacommitowanych zmian — jeśli są, uruchom `flutter analyze`, napraw ewentualne problemy i zacommituj.
2. Sprawdź jakie są dostępne urządzenia pod `flutter devices`.
3. Powiedz mi, żebym przygotował uruchomione urządzenie do testów integracyjnych. Może to być emulator/symulator (np. iOS Simulator lub Android Emulator) albo (najlepiej) fizyczne urządzenie podłączone kablem.
4. Poinformuj mnie, że w przypadku fizycznego urządzenia powinienem wyłączyć automatyczną blokadę ekranu, tak żeby urządzenie nie usypiało się samo podczas testów.
5. ZATRZYMAJ SIĘ i czekaj, aż potwierdzę gotowość. Gdy będę gotowy, mam napisać `next`.
