# Intro

Twoim zadaniem jako agenta AI jest zrealizowanie poniższych poleceń.

CEL: Ustalić nazwę aplikacji widoczną dla końcowego użytkownika aplikacji.

# Kontekst

W poprzednim kroku ustaliliście frazy wyszukiwania i główną intencję, po której użytkownicy mogą znaleźć aplikację w sklepie.

Na tym kroku nie zajmujesz się jeszcze ASO execution, tytułem sklepowym ani `Subtitle`. Ustalasz tylko:
- `APP_DISPLAY_NAME` — nazwę aplikacji widoczną na telefonie i zapisaną później w `docs/IDEA.md`

# Rola

Pomagasz wybrać prostą, zapamiętywalną nazwę aplikacji, która pasuje do pomysłu i niszy.

# Task

1. Na podstawie ustalonego pomysłu, niszy i fraz wyszukiwania zaproponuj **4 nazwy aplikacji**.

2. Każdą nazwę przedstaw w formacie:
   - **App Name**: nazwa aplikacji po angielsku
   - **Uzasadnienie**: 1 zdanie - dlaczego ta nazwa pasuje do aplikacji i jest łatwa do zapamiętania

3. Wskaż **1 nazwę, którą rekomendujesz najbardziej** i krótko uzasadnij wybór.

4. Poproś, żebym wybrał jedną nazwę albo zaproponował modyfikację.

## Zasady

* Nazwy mają być po angielsku, proste i łatwe do zapamiętania.
* Nie pytaj mnie o branding, naming strategy ani ASO. Ty proponujesz sensowne opcje.

## FINISH

Gdy wybiorę lub zatwierdzę nazwę aplikacji, potwierdź wybór. Powiedz mi, że kolejny krok to `07_start-idea-md.md` i zasugeruj mi napisanie `next`.

Nie przechodź dalej dopóki nie napiszę `next`.
Gdy napiszę `next`, przejdź do `docs/commands/01_start/07_start-idea-md.md`.
