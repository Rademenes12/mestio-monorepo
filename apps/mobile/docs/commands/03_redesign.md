# Etap `03_redesign`

## Stan workflow

Gdy zaczynasz ten etap, przeczytaj `STATE.md` i zaktualizuj go tak, aby wskazywał:
- `Aktualny etap`: `redesign`
- status etapu `redesign`: `🟡 in-progress`

Aplikacja ma już finalny Home przeniesiony do `home_screen.dart`, usunięty sandbox wariantów oraz dokument `docs/DESIGN.md`. Pozostałe ekrany template'u nie są jeszcze dopasowane do tego stylu.

W tym etapie nie robimy nowego loopa wariantów ani refactoru Home. Dopasowujemy istniejące ekrany auth/profile do kierunku wybranego w `home` i weryfikujemy całość.

Będziesz zaraz przechodził przez kolejne kroki po kolei.

# Kroki tego etapu

1. `01_redesign-audit.md` - Zrobimy audyt Home, `docs/DESIGN.md` i ekranów do dopasowania.
2. `02_redesign-auth-screens.md` - Dopasujemy ekrany auth do `docs/DESIGN.md`.
3. `03_redesign-profile-screens.md` - Dopasujemy Profile/Delete Account i powierzchnie profilowe.
4. `04_redesign-verify.md` - Zweryfikujemy Home/auth/profile/delete i przejdziemy do `plan`.

# Start

Wykonaj polecenie z pliku `docs/commands/03_redesign/01_redesign-audit.md`.

Nie przechodź sam do kolejnych kroków bez mojego polecenia.
