# Etap `04_plan`

## Stan workflow

Gdy zaczynasz ten etap, przeczytaj `STATE.md` i zaktualizuj go tak, aby wskazywał:
- `Aktualny etap`: `plan`
- status etapu `plan`: `🟡 in-progress`

Aplikacja ma już pomysł, ekran Home i kierunek wizualny, ale jeszcze nic nie działa. Jest zrobiony tylko wstępny presentation layer.

W tym etapie zaplanujemy budowę aplikacji na małe kroki.

Będziesz zaraz przechodził przez kolejne kroki po kolei.

# Kroki tego etapu

1. `01_plan-explore.md` - Poznamy aktualny kod aplikacji.
2. `02_plan-plan.md` - Przygotujemy plan implementacji.
3. `03_plan-baby-steps.md` - Rozbijemy plan na małe kroki.
4. `04_plan-prepare-tests.md` - Przygotujemy scenariusze testów manualnych.

# Start

Wykonaj polecenie z pliku `docs/commands/04_plan/01_plan-explore.md`.

Nie przechodź sam do kolejnych kroków bez mojego polecenia.
