# Etap `01_start`

## Stan workflow

Gdy zaczynasz ten etap, przeczytaj `STATE.md` i zaktualizuj go tak, aby wskazywał:
- `Aktualny etap`: `start`
- status etapu `start`: `🟡 in-progress`

Projekt jest już wstępnie skonfigurowany po etapie `00_init`, ale wciąż kod to pusty template. Aplikacja nadal nie ma jeszcze pomysłu, niszy, nazwy ani technicznej tożsamości produktu.

W tym etapie ustalimy, jaką aplikację będziemy budować.

Będziesz zaraz przechodził przez kolejne kroki po kolei.

# Kroki tego etapu

1. `01_start-about-them.md` - Poznamy mnie jako autora aplikacji.
2. `02_start-learn-idea-template.md` - Poznamy strukturę opisu pomysłu.
3. `03_start-do-you-have-idea.md` - Wybierzemy kierunek aplikacji.
4. `04_start-niche.md` - Zawęzimy niszę i odbiorców.
5. `05_start-long-tail-keyword.md` - Wybierzemy frazy wyszukiwania.
6. `06_start-app-name.md` - Wybierzemy nazwę aplikacji.
7. `07_start-idea-md.md` - Zapiszemy pomysł w `docs/IDEA.md`.
8. `08_start-app-bundle-id.md` - Ustawimy identyfikatory aplikacji.
9. `09_start-app-name.md` - Ustawimy nazwę widoczną w systemie.
10. `10_start-agents-md.md` - Zaktualizujemy kontekst dla agentów.
11. `11_start-app-identity.md` - Ustawimy tożsamość aplikacji w Supabase.
12. `12_start-platform-app-id.md` - Dodamy aplikację do platformy.
13. `13_start-checklist.md` - Sprawdzimy, czy etap `start` jest gotowy.

# Start

Wykonaj polecenie z pliku `docs/commands/01_start/01_start-about-them.md`.

Nie przechodź sam do kolejnych kroków bez mojego polecenia.
