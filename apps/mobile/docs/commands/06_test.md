# Etap `06_test`

## Stan workflow

Gdy zaczynasz ten etap, przeczytaj `STATE.md` i zaktualizuj go tak, aby wskazywał:
- `Aktualny etap`: `test`
- status etapu `test`: `🟡 in-progress`

Aplikacja ma już zaimplementowane główne funkcje MVP. Teraz trzeba sprawdzić, czy działa stabilnie przed publikacją.

W tym etapie przetestujemy aplikację i poprawimy znalezione problemy.

Będziesz zaraz przechodził przez kolejne kroki po kolei.

# Kroki tego etapu

1. `01_test-manual.md` - Przejdziemy przez testy manualne.
2. `02_test-integration-decision.md` - Zdecydujemy, czy potrzebujemy testów integracyjnych.
3. `03_test-integration-scope.md` - Wybierzemy zakres testów integracyjnych.
4. `04_test-integration-create.md` - Przygotujemy najważniejsze testy integracyjne.
5. `05_test-setup.md` - Przygotujemy urządzenie lub emulator.
6. `06_test-integration-run.md` - Uruchomimy testy integracyjne.
7. `07_test-finish.md` - Zamkniemy etap testów.

# Start

Wykonaj polecenie z pliku `docs/commands/06_test/01_test-manual.md`.

Nie przechodź sam do kolejnych kroków bez mojego polecenia.
