## Applied Optimizations

### 1. Image Optimization (all 3 apps)

- **`images.formats`**: `['image/avif', 'image/webp']` — serves next-gen formats with automatic fallback
- **`images.deviceSizes`**: `[640, 750, 828, 1080, 1200, 1920, 2048, 3840]` — responsive srcset generation
- **`images.imageSizes`**: `[16, 32, 48, 64, 96, 128, 256, 384]` — granular sizes for layout images

> ⚠️ **Action required**: `apps/web/public/og-image.png` is 5.6 MB. Convert to WebP/AVIF and resize to 1200×630 (current OG dimensions). Expected savings: ~95%.

### 2. Font Optimization

- **`display: 'swap'`** added to all Google Fonts in `apps/web` and `apps/crm-owner`
- **`fallback`** system fonts specified per font family:
  - `Space_Grotesk` → `system-ui, sans-serif`
  - `IBM_Plex_Sans` → `system-ui, sans-serif`
  - `IBM_Plex_Mono` → `ui-monospace, monospace`
- Fonts are self-hosted via `next/font/google` — zero external requests, no FOUT penalty

### 3. Bundle Optimization (all 3 apps)

- **`modularizeImports`** for `lucide-react` — tree-shakes individual icons via ESM path transform:
  ```
  lucide-react → lucide-react/dist/esm/icons/{{member}}
  ```
  Result: only imported icons land in the bundle, not the entire icon library.

- **`experimental.optimizePackageImports`**: `['lucide-react', '@supabase/supabase-js']`
  — Next.js pre-bundles these packages server-side for faster cold starts and reduced client-side weight

### 4. Caching Headers (all 3 apps)

| Asset Path           | Cache-Control                                     |
|----------------------|---------------------------------------------------|
| `/_next/static/*`    | `public, max-age=31536000, immutable` (1 year)    |
| `/fonts/*`           | `public, max-age=31536000, immutable` (1 year)    |
| `/images/*`          | `public, max-age=86400, stale-while-revalidate=604800` (1 day + 7 day SWR) |

Next.js static assets (chunk hashes in filenames) are permanently cacheable. Images use shorter TTL with stale-while-revalidate for content updates.

### 5. Security Headers (all 3 apps — pre-existing, retained)

- CSP with strict directives
- HSTS (2 years, includeSubDomains, preload)
- X-Frame-Options: DENY
- X-Content-Type-Options: nosniff
- Referrer-Policy: strict-origin-when-cross-origin
- Permissions-Policy: camera/microphone/geolocation disabled

### 6. Turbo Config

- **`globalDependencies`**: `['**/.env*', '**/tsconfig*.json']` — cache invalidation on any env or TypeScript config change
- **`globalEnv`**: centralized env var list shared across all tasks
- **Build cache**: outputs `.next/**` (excluding `.next/cache/**`), cache keyed on `$TURBO_DEFAULT$` + `.env*` files
- Dev tasks: uncached (`cache: false`), persistent — correct

### 7. ISR / Blog Pages

- No blog pages exist in `apps/web`. If added later, configure `revalidate` in page-level `fetch` options or `export const revalidate` segment config.
- Stale-while-revalidate image caching provides ISR-like behavior for static images.
